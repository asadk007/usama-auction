AUCTION CAR INSPECTOR — FREE OFFLINE WEB APP

Contains all 77 vehicles from the supplied CSV.

SETUP (RECOMMENDED FOR PHONE):
1. Upload index.html, sw.js and manifest.webmanifest together to a free HTTPS static hosting service (such as GitHub Pages).
2. Open the hosted URL on the inspector phone while online and wait for the car list to appear.
3. Add to Home Screen if desired. Turn on airplane mode and test reopening the app before auction day.
4. Inspect vehicles. Save & exit retains incomplete work. Issue comments are mandatory.
5. After each session, choose Backup & Export > Backup with photos. Share that JSON backup to a safe place.
6. Export Excel (.xlsx) for buying comparisons. Excel export does not include photos; JSON backup does.

LOCAL TEST: Open index.html on a desktop browser; local-file operation varies across mobile browsers.

NOTES: Each device has its own data. No automatic sync. Avoid private mode. Clearing site data may erase records. Photos are compressed to reduce storage. Verify imported auction list details against the original auction notice.
